# Fluid ERP

A fast, keyboard-first, Tally-style front end for ERPNext, packaged as a Frappe app. ERPNext stays the system of record (books, stock, users, permissions); Fluid ERP adds the screens at `https://<your-site>/fluid`.

- Design plan: [docs/PLAN.md](docs/PLAN.md)
- Screen ↔ ERPNext mapping and hosting notes: [docs/FRAPPE.md](docs/FRAPPE.md)
- Dashboard web pages, DRI Production print formats and the daily Telegram PDF: [docs/erpnext/README.md](docs/erpnext/README.md)

## Install on Frappe Cloud

1. Push this repository to GitHub.
2. On Frappe Cloud, open your private bench → Apps → Add app → from GitHub, pick this repo and branch.
3. Deploy the bench, then install **Fluid ERP** on your site (ERPNext must already be installed).
4. Open `https://<your-site>/fluid`. You sign in with your normal ERPNext login.

Self-hosted bench: `bench get-app <repo-url> && bench --site <site> install-app fluid_erp`.

## Layout

```
fluid_erp/          Frappe app (Python)
  hooks.py          routes /fluid/* to the single-page app
  www/fluid.py      login check, CSRF token and boot info for the page
  www/fluid.html    generated by the front-end build
  public/fluid/     generated JS/CSS bundle (committed, so no build step is needed on deploy)
  fluid_erp/        module "Fluid ERP": dashboard web pages, DRI Production print formats and
                    Telegram server scripts, synced to the site on migrate (see docs/erpnext)
frontend/           React + TypeScript source (Vite)
docs/               plan and ERPNext mapping
```

## Front-end development

```bash
cd frontend
npm install
npm run dev            # standalone demo with sample data, http://localhost:5173
npm test               # unit tests
npm run build:frappe   # rebuild fluid_erp/public/fluid and fluid_erp/www/fluid.html, then commit
```

## What works on ERPNext (v0.2)

Opened at `/fluid` on your site, Fluid reads and writes your ERPNext data with your login and permissions:

- Purchase Order, Purchase Receipt, Purchase Invoice, Sales Order, Delivery Note and Sales Invoice: keyboard entry (Shift+F9, Alt+F9, F9, Shift+F8, Alt+F8, F8), saved and submitted in ERPNext.
- On a saved document: R receive, B bill, D deliver, I invoice, P pay / receive (uses ERPNext's own "make" mappings, so links and pending quantities are ERPNext's), X cancel, O open in ERPNext.
- Day Book, purchase and sales cycle boards, stock summary, Ctrl+K search by document number.
- Payment and Receipt from a bill or invoice (P). Standalone payments, journals and contra open in ERPNext for now.
- Reports inside Fluid: Trial Balance, Profit & Loss, Balance Sheet, Receivables, Payables (ERPNext's own reports, drawn in Fluid). Enter drills from an account to its ledger, and from a ledger line to the voucher.

Opened anywhere else (or `npm run dev`), it shows the demo company instead.

Not tested against a live ERPNext site yet; `frontend/tests/e2e-erp.mjs` checks the screens and request shapes against a stubbed API only.
